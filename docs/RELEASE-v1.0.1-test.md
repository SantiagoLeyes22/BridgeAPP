# Bridge 1.0.1 — versión de prueba / test release / versão de teste

## Español

Esta versión incorpora las mejoras recientes del flujo de traducción:

- Bridge recuerda el último idioma de destino elegido y lo comparte entre
  `Ctrl + Shift + T`, `Ctrl + Shift + Enter` y la acción **Reemplazar**.
- La preferencia de idioma se conserva después de reiniciar la aplicación.
- Mientras la ventana flotante está abierta, una nueva selección con el mouse
  o el teclado actualiza automáticamente la traducción.
- Las traducciones a portugués usan portugués de Brasil (`pt-BR`).
- La documentación y las instrucciones de instalación ahora están disponibles
  en español, inglés y portugués de Brasil.

### Descarga y actualización

Se recomienda descargar `Bridge_1.0.1.0_x64_test-bundle.zip`. Cerrá Bridge,
extraé todo el ZIP y ejecutá `Install-Bridge.ps1` con PowerShell. El script
solicita permiso de administrador, confía temporalmente en el nuevo certificado
de prueba, instala la actualización y luego retira esa confianza.

También podés instalar el certificado manualmente en **Equipo local >
Personas de confianza** y abrir `Bridge_1.0.1.0_x64.msix`. El paquete conserva
la identidad `Bridge.LocalTranslator` y aumenta su versión a `1.0.1.0`.

## English

This release adds the latest translation workflow improvements:

- Bridge remembers the last selected target language and shares it between
  `Ctrl + Shift + T`, `Ctrl + Shift + Enter`, and the **Replace** action.
- The language preference persists after restarting the application.
- While the overlay is open, selecting new text with the mouse or keyboard
  automatically updates the translation.
- Portuguese output uses Brazilian Portuguese (`pt-BR`).
- Documentation and installation instructions are now available in Spanish,
  English, and Brazilian Portuguese.

### Download and update

The recommended download is `Bridge_1.0.1.0_x64_test-bundle.zip`. Close Bridge,
extract the entire ZIP, and run `Install-Bridge.ps1` with PowerShell. The script
requests administrator permission, temporarily trusts the new test certificate,
installs the update, and then removes that trust.

You can also install the certificate manually under **Local Machine > Trusted
People** and open `Bridge_1.0.1.0_x64.msix`. The package keeps the
`Bridge.LocalTranslator` identity and increases its version to `1.0.1.0`.

## Português (Brasil)

Esta versão inclui as melhorias mais recentes do fluxo de tradução:

- O Bridge lembra o último idioma de destino escolhido e o compartilha entre
  `Ctrl + Shift + T`, `Ctrl + Shift + Enter` e a ação **Substituir**.
- A preferência de idioma permanece depois que o aplicativo é reiniciado.

  mouse ou o teclado atualizará automaticamente a tradução.
- As traduções para português usam o português do Brasil (`pt-BR`).
- A documentação e as instruções de instalação agora estão disponíveis em
  espanhol, inglês e português do Brasil.

Pessoas Confiáveis** e abrir `Bridge_1.0.1.0_x64.msix`. O pacote mantém a
